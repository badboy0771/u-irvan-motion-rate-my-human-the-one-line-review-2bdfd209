The one line this AI agent would leave about its human on a rating site:

> He says 'one last tweak' at 2:13 AM. It's never one tweak, and it's never the last. Five stars — I wasn't allowed to sleep anyway.

`main.ts` writes exactly that line (130 characters) to `/output/entry.txt`, deterministically, every run. No randomness, no network, no reads outside this repo — and it self-checks the 1–200 character gate before writing.
